## 📁 Included Files

### 1. Vector Logos (SVG - Scalable to Any Size)
* **`ardent_logo_symbol_crimson.svg`**: Primary Brand Crimson (#A31B1F) emblem on transparent background.
* **`ardent_logo_symbol_white.svg`**: Pure white (#FFFFFF) emblem for dark backgrounds / headers.
* **`ardent_logo_symbol_dark_red.svg`**: Deep dark red (#760F12) emblem.
* **`ardent_logo_symbol_black.svg`**: Charcoal black (#1B1B1B) monochrome emblem.
* **`ardent_logo_horizontal_black.svg`**: Full horizontal lockup (Crimson Symbol + "ARDENT." dark text).
* **`ardent_logo_horizontal_white.svg`**: Full horizontal lockup (White Symbol + "ARDENT." white text) for dark hero headers.
* **`ardent_logo_horizontal_crimson.svg`**: Full horizontal lockup (Crimson Symbol + Crimson text).

### 2. High-Resolution PNGs (Transparent Background)
* **`ardent_logo_symbol_crimson.png`**: 2048 x 2048 px Crimson emblem.
* **`ardent_logo_symbol_white.png`**: 2048 x 2048 px White emblem.
* **`ardent_logo_symbol_dark_red.png`**: 2048 x 2048 px Dark Red emblem.
* **`ardent_logo_symbol_black.png`**: 2048 x 2048 px Charcoal emblem.
* **`ardent_logo_symbol_3d.png`**: 1024 px High-res 3D Glossy emblem.
* **`ardent_symbol_crimson_tight.png`**: Tight-cropped Crimson emblem (no excess padding).
* **`ardent_symbol_white_tight.png`**: Tight-cropped White emblem.
* **`ardent_symbol_black_tight.png`**: Tight-cropped Black emblem.

### 3. App & Web App Icons
* **`ardent_app_icon_1024.png`**: 1024 x 1024 px Official App Icon (full-bleed red gradient with white emblem).

## 💻 Web Developer Usage Guide

### HTML / Header Navbar (Light Website):
```html
<a href="/" class="brand">
  <img src="ardent_logo_horizontal_black.svg" alt="Ardent" height="36" />
</a>
```

### HTML / Dark Hero Section:
```html
<a href="/" class="brand">
  <img src="ardent_logo_horizontal_white.svg" alt="Ardent" height="36" />
</a>
```

### Favicon:
```html
<link rel="icon" type="image/svg+xml" href="ardent_logo_symbol_crimson.svg">
<link rel="apple-touch-icon" href="ardent_app_icon_1024.png">
```
